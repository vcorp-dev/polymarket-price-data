# Contributing

Contributions that improve the Python client, runnable examples, documentation, or test coverage are welcome.

## Workflow

1. Open an issue describing the change.
2. Create a focused branch and include tests or a reproducible example where applicable.
3. Never commit DepthFeed API keys, tokens, customer information, or downloaded private data.
4. Run the keyless examples and any relevant tests before opening a pull request.
5. Link product claims to the current [DepthFeed API documentation](https://depthfeed.com/docs).

For product or account support, use [DepthFeed support](https://depthfeed.com/contact).
